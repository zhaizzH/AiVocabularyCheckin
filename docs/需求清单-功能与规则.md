# 需求清单：功能与行为规则

> 本文档是 S2《软件需求规格说明书》的落地细化版，面向开发执行。
> 每个功能点给出：行为规则、边界情况、页面状态。与 S2/S3 冲突时以 S2/S3 为准。
> 版本：V1.0 · 2026-10-16

---

## 0. 全局约定

| 项 | 规则 |
|---|---|
| 接口响应 | 统一 `{ code, message, data }`，`code: "0"` 成功；业务失败 HTTP 仍 200 |
| 错误码 | 1xxx 认证/用户、2xxx 词库、3xxx 学习/打卡、4xxx 错题、5xxx AI、9xxx 系统 |
| 鉴权 | 除注册/登录/微信登录外全部携带 JWT；401 时前端清 token 跳登录页；`/api/admin/**` 校验 ADMIN |
| 路径规范 | 用户端接口 `/api/client/**`，管理端接口 `/api/admin/**`；字段级契约见《接口详细设计.md》 |
| 分页 | 列表接口一律分页，默认 page=1, size=20 |
| 空状态 | 每个列表页都必须设计空状态文案与引导动作 |
| 加载/失败 | AI 操作必须有加载态、超时提示、降级文案；普通接口失败 toast 提示可重试 |

## 1. 用户模块

### 1.1 注册
- 用户名 4–20 位（字母/数字/下划线），密码 ≥6 位且含字母+数字，确认密码前端比对
- 密码 BCrypt 入库；注册成功默认角色 USER、status=1
- 边界：用户名重复 → 1001「用户名已被占用」；格式不符前端就地提示，不发请求

### 1.2 登录
- 账号密码校验成功 → 签发 JWT（userId、role、有效期 7 天），返回 token + 用户信息
- 边界：密码错误 → 1002；账号被禁用 → 1003「账号已被禁用，请联系管理员」
- 登录失败记 WARN 日志（不含密码）

### 1.3 个人信息
- 可修改：昵称（≤20 字）、头像（一期：6 个内置头像选一个，不做文件上传）
- 可查看：用户名（不可改）、注册时间、累计打卡天数
### 1.4 微信登录（学生端主入口，已决策纳入一期）
- 小程序端一键微信登录：`wx.login` 拿 code → `POST /api/client/auth/wx-login` → 后端 code2Session 换 openid
- openid 不存在则自动创建用户（默认昵称「微信用户+随机后缀」、默认内置头像），响应 `isNewUser=true` → 前端引导设置昵称
- 账号密码登录保留：管理端管理员使用，学生端作为备用入口
- 前提：组长注册微信小程序获取 AppID（个人主体免费，需实名）；开发期可用测试号
- user 表新增 `openid` 字段（唯一索引，可空）

## 2. 词库学习模块（核心链路）

### 2.1 词库浏览与选择
- 词库列表按分类 Tab 筛选：四级 / 六级 / 考研；卡片显示词书名、单词数、简介、「已加入」标记
- 可同时选择多本词书；再次点击已选词书可「移出」（二次确认）
- 内置种子词书：四级（7508 词）、六级（5651 词）、考研（9602 词），来源 KyleBing/english-vocabulary（BSD 3-Clause，界面「关于」页注明出处）

### 2.2 每日学习计划
- 规则：每本已选词书每日 20 个新词（常量配置 `DAILY_NEW_WORDS=20`），取该词书内未学单词按 id 升序
- 若今日有待复习单词，复习词排在计划列表最前
- 边界：词书全部学完 → 返回空计划 + 「本词书已学完」提示；未选词书 → 引导去选词书

### 2.3 学习卡片
- 正面：单词 + 英式音标；点击卡片翻面显示释义（translations 拼接：词性+中文）
- 两个操作按钮：「认识」→ 标记已学，下一张；「不认识」→ 标记已学 + **立即收录错题本**，下一张
- 卡片上提供「AI 例句」入口（见 4.1）
- 计划内单词全部过完 → 打卡按钮点亮

### 2.4 打卡
- 点击打卡 → 写入学习记录、更新 check_in_date 与 streak_days
- 连续天数规则：上次打卡日期 = 昨天 → streak+1；否则重置为 1
- 幂等：同日重复打卡 → 3001「今日已打卡」，前端打卡后按钮变为「已打卡 ✓」
- 打卡成功页：显示连续天数 + 今日学习词数 + 错题数

## 3. 复习巩固模块

### 3.1 错题本
- 收录来源：学习中点「不认识」、复习中答错（source=STUDY/REVIEW）；同一单词重复错 → wrong_count+1 不重复建记录
- 列表分页展示：单词、释义、错误次数、来源、是否已掌握；可按「未掌握/已掌握」筛选
- 操作：AI 讲解（见 4.2）、标记已掌握（mastered=1）、手动移除（二次确认，逻辑删除）

### 3.2 间隔复习
- 算法（已定为常量，写死即可）：复习间隔序列 1 → 3 → 7 → 15 天
- 规则：学习/复习完成后按当前阶段设置下次复习日期；答对进入下一阶段，答错退回第 1 阶段（1 天后）并 wrong_count+1
- 「今日待复习列表」= 下次复习日期 ≤ 今天 且未掌握的单词，计算生成、不建表存储
- 复习作答界面同学习卡片（翻面 + 认识/不认识）

## 4. AI 增强模块（全部可降级）

### 4.1 AI 例句生成
- 入口：学习卡片 / 错题详情；后端中转 `/api/client/ai/example` → ai-service（超时 15s）
- 输出：1 个例句（英文）+ 中文翻译 + 1 条助记提示
- 降级：失败/超时 → 展示该单词词库自带例句（word.example），顶部提示「AI 暂时不可用，展示内置例句」

### 4.2 AI 错题讲解
- 入参：单词、用户作答、错误上下文；超时 30s
- 输出：讲解文本（为什么错/易混点）+ 学习建议；讲解页底部有「标记已掌握」按钮
- 降级：失败 → 「AI 讲解暂时不可用，请稍后再试」，不影响标记已掌握

### 4.3 AI 学习报告
- 入参：后端汇总的学习统计（学习天数、打卡率、错题分布、掌握度）；超时 60s
- 生成前校验：学习天数 < 3 天 → 直接返回「数据还太少，学几天再来生成报告」，**不调用 AI**
- 输出：分段文本报告（学习概况 / 薄弱环节 / 建议）
- 降级：失败 → 「报告生成失败，请稍后重试」；报告不缓存，每次实时生成

## 5. 数据统计模块

### 5.1 打卡热力图
- 按 `check_in_date` 聚合近 12 周数据，日历格展示（颜色深浅 = 当日学习词数分档：0 / 1–10 / 11–20 / 21+）
- SQL 聚合完成，不加载原始记录

### 5.2 掌握度曲线
- 按天聚合近 30 天：学习词数、复习词数、错题数；掌握度 = 已掌握错题 / 总错题
- 折线图展示，默认近 30 天

## 6. 管理模块（网页管理端，Ant Design 5）

### 6.1 词库管理
- 词书表格：名称、分类、单词数、创建时间、操作（查看单词 / 删除）
- 词库导入：上传 JSONL 文件 → 前端预览前 20 行 → 确认后后端校验（字段缺失/格式错误行跳过并计数）→ saveBatch 批量写入 → 返回「成功 N 条，跳过 M 条」
- 单词管理弹窗：单词分页表格 + 新增/编辑/删除（删除二次确认）
- 导入字段映射：word→word、uk→phonetic、translations 拼接「词性. 释义」→translation、sentences[0]→example

### 6.2 用户管理
- 用户表格分页 + 用户名搜索；操作：禁用 / 启用
- 禁用即时生效：该用户 JWT 下次校验即失败（接口层校验 status）
- 操作记 INFO 日志（操作者 id、动作、目标用户）

### 6.3 系统监控
- AI 调用统计卡片：今日例句/讲解/报告调用次数、成功率、降级次数
- 降级事件列表：时间、功能、耗时（从日志聚合，一期可用简单内存计数器实现）
