## 4. 缺陷记录（开发期已修复的典型问题）

| 编号 | 问题 | 根因 | 修复 |
|---|---|---|---|
| BUG-01 | 复习词永久卡在列表 | 前端引用了不存在的错误码常量（JS 静默 undefined） | 修拼写 + 加静态门禁 `check_error_code_refs` |
| BUG-02 | 管理端整页白屏 | `useSyncExternalStore` 快照每次返回新对象 → 无限重渲染 | 快照返回原始字符串 + useMemo 解析 |
| BUG-03 | 打卡按钮假禁用 | 学完最后一词未 await 计划刷新 | `advance()` 后强制 `await loadPlan()` |
| BUG-04 | 统计空态误显示掌握度 100 | 后端无数据时默认 100 | 空态判据改为三个计数全 0 |
