## 四、填写避坑清单（对照官方审核规则）

1. ✅ 简介必须**具体**写功能点（词库/打卡/错题/AI 三项），不写「提升学习体验」这类模糊话术
2. ✅ 简介里要能**找到名称中的词**（如上文中「跃单词」「词搭子」均在简介中出现，保持一致）——这是官方明确的一致性要求
3. ❌ 不写「小程序」三个字；不写联系方式（微信/QQ/电话）
4. ❌ 禁用极限词与广告语（最、第一、免费领、点击领取）
5. ✅ AI 功能如实描述为「生成例句/讲解错题/学习报告」，不夸大（如「包过四六级」禁止）
6. 📄 头像上传用 docs/logo/ 下的 144×144 版本（G3 纯平绿 或 G1 鲜绿渐变）；头像须与名称简介一致、清晰无第三方标识

## 五、服务类目建议

- 个人主体：建议选 **教育 → 教育信息服务**（如不可选，退而选 **工具 → 效率**），无需额外资质
- 若后续注册为企业主体，可选教育类目并补充相应证明
- 类目必须覆盖全部功能（背词工具 + 教育信息），只选一类即可通过；不要把「AI」单独当作类目（无此选项）
