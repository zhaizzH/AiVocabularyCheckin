# 接口详细设计（契约文档 · 冻结版）

> 本文档是前后端、业务后端与 AI 微服务之间的**唯一接口契约**。编码严格按本文档执行；要改接口，先改本文档。
> 版本：V1.0 · 2026-10-16（路径规范：用户端 `/api/client/**`，管理端 `/api/admin/**`）

## 0. 通用约定

**响应包装**：所有接口返回统一结构，业务失败 HTTP 状态仍为 200：

```json
{ "code": "0", "message": "ok", "data": {} }
```

**错误码总表**：

| 段 | 模块 | 已分配 |
|---|---|---|
| 1xxx | 认证/用户 | 1001 用户名已被占用 / 1002 用户名或密码错误 / 1003 账号已被禁用 / 1004 微信登录失败 / 1005 参数校验失败 |
| 2xxx | 词库 | 2001 词书不存在 / 2002 未选择该词书 / 2003 词书已加入 / 2004 导入文件格式错误 |
| 3xxx | 学习/打卡 | 3001 今日已打卡 / 3002 今日无学习计划 / 3003 学习计划未完成不可打卡 |
| 4xxx | 错题 | 4001 错题不存在 / 4002 错题已掌握 |
| 5xxx | AI 服务 | 5001 AI 服务超时 / 5002 AI 服务异常 / 5003 学习数据不足无法生成报告 |
| 9xxx | 系统 | 9001 系统繁忙 |

**鉴权**：除注册/登录/微信登录外，请求头携带 `Authorization: Bearer <token>`；401 = token 缺失/过期/账号禁用；403 = 非管理员访问 `/api/admin/**`。
**分页**：请求参数 `page`（默认1）、`size`（默认20）；响应统一 `{ list: [], total: 0, page: 1, size: 20 }`。
**字段命名**：JSON 一律小驼峰；日期格式 `YYYY-MM-DD`，时间 `YYYY-MM-DD HH:mm:ss`。

## 1. 认证模块（/api/client/auth）

### 1.1 注册 `POST /api/client/auth/register`

请求：

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| username | string | ✓ | 4–20 位，字母/数字/下划线 |
| password | string | ✓ | ≥6 位，含字母+数字 |
| nickname | string | – | ≤20 字，缺省取 username |

响应 data：

```json
{ "userId": 1001, "username": "zhangsan", "nickname": "张三", "role": "USER" }
```

错误码：1001、1005

### 1.2 账号密码登录 `POST /api/client/auth/login`

请求：`{ "username": "zhangsan", "password": "abc123" }`

响应 data：

```json
{
  "token": "eyJhbGciOi...",
  "userInfo": { "userId": 1001, "username": "zhangsan", "nickname": "张三", "avatar": "avatar_1", "role": "USER" }
}
```

错误码：1002、1003。说明：管理员也走此接口登录管理端，由 role 区分。

### 1.3 微信登录 `POST /api/client/auth/wx-login`

请求：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| code | string | ✓ | 小程序 `wx.login()` 返回的临时凭证 |

后端行为：code → 微信 `code2Session` 换 openid → openid 已存在则直接登录；不存在则**自动创建用户**（role=USER，nickname 缺省「微信用户+随机后缀」，头像默认 avatar_1）→ 签发 JWT。

响应 data：同 1.2，额外多一个字段：

```json
{ "token": "...", "userInfo": { "userId": 1002, "nickname": "微信用户8f3k", "isNewUser": true } }
```

`isNewUser: true` 时前端引导进入「设置昵称」页。

错误码：1004（code 无效或微信侧异常）

### 1.4 获取个人信息 `GET /api/client/auth/profile`

响应 data：

```json
{ "userId": 1001, "username": "zhangsan", "nickname": "张三", "avatar": "avatar_1",
  "role": "USER", "createTime": "2026-10-18 09:30:00", "totalCheckInDays": 12 }
```

### 1.5 修改个人信息 `PUT /api/client/auth/profile`

请求（均可选，至少一项）：`{ "nickname": "新昵称", "avatar": "avatar_3" }`
约束：avatar 仅限 `avatar_1` ~ `avatar_6` 内置值。
响应 data：更新后的完整 profile（同 1.4）。
错误码：1005

## 2. 词库模块（/api/client/books）

### 2.1 词库列表 `GET /api/client/books?category=CET4`

query：`category` 可选（CET4 / CET6 / KAOYAN），缺省返回全部。

响应 data：`list` 数组，元素：

```json
{ "bookId": 1, "name": "四级核心词汇", "category": "CET4", "wordCount": 7508,
  "description": "…", "selected": true, "learnedCount": 346 }
```

`selected` = 当前用户是否已加入；`learnedCount` = 该用户在此词书已学词数。

### 2.2 词书详情 `GET /api/client/books/{bookId}?page=1&size=20`

响应 data：

```json
{ "bookId": 1, "name": "四级核心词汇", "category": "CET4", "wordCount": 7508,
  "words": { "list": [
    { "wordId": 101, "word": "abandon", "phonetic": "əˈbændən",
      "translation": "v. 放弃；抛弃", "example": "He decided to abandon the plan." }
  ], "total": 7508, "page": 1, "size": 20 } }
```

错误码：2001

### 2.3 选择词书 `POST /api/client/books/{bookId}/select`

无请求体。响应 data：`{ "bookId": 1, "selected": true }`
错误码：2001、2003

### 2.4 移出词书 `DELETE /api/client/books/{bookId}/select`

响应 data：`{ "bookId": 1, "selected": false }`。历史学习记录保留。
错误码：2001、2002

## 3. 学习模块（/api/client/study）

### 3.1 今日学习计划 `GET /api/client/study/plan`

响应 data：

```json
{
  "date": "2026-10-16",
  "total": 20, "finished": 14,
  "checkedIn": false,
  "words": [
    { "wordId": 101, "bookId": 1, "word": "abandon", "phonetic": "əˈbændən",
      "translation": "v. 放弃；抛弃", "example": "…", "isReview": false, "learned": false }
  ]
}
```

规则：复习词（isReview=true）排在新词前；`learned=true` 的词前端跳过不展示；未选词书时 `total=0, words=[]`。

### 3.2 学习结果上报（逐词）`POST /api/client/study/record`

> 用于「认识/不认识」逐词标记；不认识自动收录错题本。

请求：`{ "wordId": 101, "bookId": 1, "known": false }`
响应 data：`{ "wordId": 101, "learned": true, "addedToMistakes": true }`

### 3.3 打卡 `POST /api/client/study/checkin`

无请求体。前置：当日计划词全部 learned。
响应 data：

```json
{ "checkInDate": "2026-10-16", "streakDays": 12, "todayLearned": 20, "todayMistakes": 3 }
```

错误码：3001（幂等，前端按钮变「已打卡」）、3002、3003

### 3.4 连续打卡天数 `GET /api/client/study/streak`

响应 data：`{ "streakDays": 12, "totalLearned": 346, "todayReviewCount": 8, "lastCheckInDate": "2026-10-15" }`

## 4. 复习模块（/api/client/review）

### 4.1 今日待复习 `GET /api/client/review/today`

响应 data：

```json
{ "total": 8, "words": [
  { "wordId": 101, "word": "tremendous", "phonetic": "trəˈmendəs",
    "translation": "adj. 巨大的", "example": "…", "stage": 2, "wrongCount": 1 }
] }
```

`stage` = 当前间隔阶段（1–4，对应 1/3/7/15 天）。

### 4.2 提交复习结果 `POST /api/client/review/record`

请求：`{ "wordId": 101, "correct": true }`

规则：correct=true → stage+1（最高 4）；correct=false → stage 重置为 1、wrongCount+1、确保收录错题本。

响应 data：`{ "wordId": 101, "stage": 3, "nextReviewDate": "2026-10-23" }`

## 5. 错题模块（/api/client/mistakes）

### 5.1 错题列表 `GET /api/client/mistakes?mastered=0&page=1&size=20`

query：`mastered` 可选（0 未掌握 / 1 已掌握），缺省 0。

响应 data（分页结构）：

```json
{ "list": [
  { "mistakeId": 501, "wordId": 101, "word": "abandon", "phonetic": "…",
    "translation": "v. 放弃", "source": "STUDY", "wrongCount": 3,
    "mastered": false, "createTime": "2026-10-14 21:03:11" }
], "total": 12, "page": 1, "size": 20 }
```

### 5.2 标记已掌握 `POST /api/client/mistakes/{mistakeId}/mastered`

响应 data：`{ "mistakeId": 501, "mastered": true }`
错误码：4001、4002

### 5.3 移除错题 `DELETE /api/client/mistakes/{mistakeId}`

逻辑删除。响应 data：`{ "mistakeId": 501, "removed": true }`
错误码：4001

## 6. AI 模块（/api/client/ai，全部经后端中转，可降级）

### 6.1 AI 例句 `POST /api/client/ai/example`

请求：`{ "wordId": 101 }`（单词与释义由后端从库中取出传给 AI，前端不传文本）

响应 data（成功）：

```json
{ "wordId": 101, "example": "He decided to abandon the plan.",
  "exampleTranslation": "他决定放弃这个计划。",
  "mnemonic": "a(一个)+bandon(板凳)→连板凳都不要了→放弃", "degraded": false }
```

降级（5001/5002 时 HTTP 仍 200，`code:"0"` 但 `degraded:true`，example 填内置例句、mnemonic 为空）——**前端按 `degraded` 显示黄条提示**，不当作错误。

### 6.2 AI 错题讲解 `POST /api/client/ai/explain`

请求：`{ "mistakeId": 501 }`

响应 data：

```json
{ "mistakeId": 501, "explanation": "你误选为「举办」。abandon 强调彻底放弃…",
  "advice": "用「放弃计划」搭配造一个自己的句子。", "degraded": false }
```

降级时不返回 data，直接错误码 5001/5002（讲解无内置兜底内容），前端展示「AI 讲解暂时不可用」。

### 6.3 AI 学习报告 `POST /api/client/ai/report`

无请求体（后端汇总统计传给 AI）。
前置校验：学习天数 < 3 → 5003（不调 AI）。

响应 data：

```json
{ "report": { "overview": "近两周共学习…", "weakness": "错题集中在…", "suggestion": "建议…" },
  "generatedAt": "2026-10-16 15:30:00", "degraded": false }
```

失败返回 5001/5002，前端给重试按钮。

## 7. 统计模块（/api/client/stats）

### 7.1 打卡热力图 `GET /api/client/stats/heatmap?weeks=12`

响应 data：

```json
{ "days": [ { "date": "2026-10-16", "wordCount": 20, "level": 2 } ] }
```

`level` 由后端分档：0=未打卡 / 1=1–10 词 / 2=11–20 词 / 3=21+ 词。

### 7.2 掌握度曲线 `GET /api/client/stats/mastery?days=30`

响应 data：

```json
{ "points": [ { "date": "2026-10-16", "learnedCount": 20, "reviewCount": 8,
  "mistakeCount": 3, "masteryRate": 58 } ] }
```

`masteryRate` = 已掌握错题 / 总错题 × 100，整数百分比。

## 8. 管理模块（/api/admin/**，需 ADMIN 角色）

### 8.1 词库导入 `POST /api/admin/books/import`

请求：`multipart/form-data` 文件上传，字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| file | File | ✓ | .jsonl 文件，一词一行，字段同 KyleBing/english-vocabulary 的 sentence 版 |
| name | string | ✓ | 词书名，如「四级核心词汇」 |
| category | string | ✓ | CET4 / CET6 / KAOYAN |

单行结构示例：`{"word":"abandon","uk":"əˈbændən","translations":[{"translation":"放弃","type":"v"}],"sentences":[{"sentence":"…","translation":"…"}]}`

映射：word→word、uk→phonetic、translations 拼接「type. translation」→translation、sentences[0]→example；格式错误行跳过并计数。

响应 data：`{ "bookId": 4, "success": 7500, "skipped": 8 }`
错误码：2004（整体格式非法时）

### 8.2 单词分页查询 `GET /api/admin/words?bookId=1&keyword=ab&page=1&size=20`

响应 data：分页结构，元素同 2.2 的 words 元素（多一个 `wordId` 必有）。

### 8.3 新增单词 `POST /api/admin/words`

请求：`{ "bookId": 1, "word": "apple", "phonetic": "ˈæpl", "translation": "n. 苹果", "example": "…" }`
响应 data：完整单词对象。错误码：2001、1005。成功后词书 wordCount+1。

### 8.4 修改单词 `PUT /api/admin/words/{wordId}`

字段同 8.3（均可选）。响应 data：更新后对象。

### 8.5 删除单词 `DELETE /api/admin/words/{wordId}`

逻辑删除，wordCount−1。响应 data：`{ "wordId": 101, "deleted": true }`

### 8.6 用户列表 `GET /api/admin/users?keyword=zhang&page=1&size=20`

响应 data：分页结构，元素：

```json
{ "userId": 1001, "username": "zhangsan", "nickname": "张三", "role": "USER",
  "status": 1, "totalCheckInDays": 12, "createTime": "2026-10-18 09:30:00" }
```

### 8.7 禁用/启用用户 `PUT /api/admin/users/{userId}/status`

请求：`{ "status": 0 }`（0 禁用 / 1 启用）
响应 data：`{ "userId": 1001, "status": 0 }`。禁用后该用户 JWT 下次校验返回 401（1003 文案）。
不允许禁用 ADMIN 账号 → 1005。

## 9. 内部接口：业务后端 → AI 微服务（ai-service，前端不可见）

统一约定：POST + JSON；密钥在 ai-service 环境变量；失败抛 HTTPException，业务后端映射为 5001/5002。

### 9.1 例句生成 `POST /ai/v1/example`（超时 15s）

请求：`{ "word": "abandon", "translation": "v. 放弃", "context": "CET4" }`
响应：`{ "example": "…", "exampleTranslation": "…", "mnemonic": "…" }`

### 9.2 错题讲解 `POST /ai/v1/explain`（超时 30s）

请求：`{ "word": "abandon", "translation": "…", "wrongContext": "用户误选「举办」" }`
响应：`{ "explanation": "…", "advice": "…" }`

### 9.3 学习报告 `POST /ai/v1/report`（超时 60s）

请求：`{ "studyStats": { "studyDays": 12, "totalLearned": 346, "checkInRate": 85, "topMistakeWords": ["abandon","…"], "masteryRate": 58 } }`
响应：`{ "overview": "…", "weakness": "…", "suggestion": "…" }`
