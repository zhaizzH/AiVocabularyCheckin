# miniprogram 学生端（微信原生小程序）

## Goal

实现学生端微信小程序，覆盖 F1–F10 全部功能模块，形成「学—练—复盘」完整闭环，并在 AI 能力异常时保持核心学习功能可用。

## 依赖与顺序

- **依赖 `10-16-backend-api` 的接口可用**（本任务的功能验证必须打到真实后端，不能只做静态页面）。
- `F1` 的微信一键登录依赖 **AppID**（用户待提供）。在拿到 AppID 前：可用账号密码登录（契约 §1.2）作为等价链路把 F2–F10 全部跑通；`wx-login` 分支待 AppID 到位后补验。
- AI 相关界面（F5/F7/F8）在无 DeepSeek key 时应验证**降级态**（这正是父任务的一等约束）。

## 需求（严格依据 `docs/学生端-需求分析与原型设计.md`）

### 全局规则

- **五个** tabBar：首页 / 学习 / 复习 / 错题 / 我的（复习与错题有待办时显示角标）。
  - **原设计为 6 个 tab（含「统计」），与微信平台限制冲突**：小程序 `tabBar.list`
    硬上限 5 项，编译器直接报错 `app.json: ["tabBar"]["list"] 不能超过 5 项`，
    自定义 tabBar（`custom: true`）同样受此限制，无法绕过。
  - 已与用户确认取舍：**去掉「统计」tab**。统计改为普通页面，入口两处：
    首页快捷入口「数据统计」、我的页功能列表「学习统计」。
    理由：统计是低频查看页，不在学习主流程上；「我的」是高频页必须常驻 tab。
- `services/` 层统一封装 API，只走 `utils/request`（baseURL、token 注入、`code !== "0"` 处理、401 清 token 跳登录页 + toast「登录已过期」）。
- 时效数据（进度、打卡状态、错题数）`onShow` 刷新；一次性数据（词书详情）`onLoad`。
- 所有提交按钮请求期间 **loading 禁用**（防重复）。
- AI 操作必须有：加载态 + 超时上限（15/30/60s）+ 降级文案。
- 单位 rpx；可点击元素 ≥ 88rpx 高。
- `globalData` + `wx.Storage` 存 token / userInfo。

### 功能清单

| 编号 | 功能 | 要点 |
|---|---|---|
| F1 | 登录/注册 | 微信一键登录为**主入口**（`wx.login` → `wx-login`）；`isNewUser=true` → 跳「设置昵称」引导页（昵称 + 6 内置头像）；账号密码登录/注册为**折叠备用入口**；注册含确认密码、前端先校验格式不发请求；失败 toast 后端 message |
| F2 | 首页 | 三卡并行请求（plan / streak / books）；进度卡含进度条与主按钮（继续学习/开始学习/今日已完成✓）；数据行（连续天数/累计已学/今日待复习）；词书卡；**任一接口失败不阻塞其他卡**；空态 A（未选词书→引导）/空态 B（词书学完→换词书）/今日已完成态 |
| F3 | 词库浏览与选择 | 分类 Tab（全部/四级/六级/考研）；卡片含词书名/分类/单词数/简介两行截断/加入按钮；已加入可移出（二次确认）；列表空态文案 |
| F4 | 每日学习（核心） | 卡片正面 word + 英式音标，点击翻面显示释义（**多义项分条**），翻面动画约 200ms；「✓ 认识」/「✗ 不认识」（不认识 → 收录错题）；卡片底部「✦ AI 例句」入口；顶部进度「词书名 · 当前/总数」；打卡按钮未达条件灰色禁用并提示「完成学习后打卡（n/20）」；打卡后成功页（连续天数大数字 + 今日词数 + 错题数 + 「查看错题」入口）；重复打卡 toast 3001 且按钮变「已打卡 ✓」 |
| F5 | AI 例句弹层 | 底部弹层 + 骨架屏；成功渲染例句（英+中）+ 助记块；**降级态**：顶部黄条「AI 暂时不可用，展示内置例句」+ 显示内部例句；例句也为空 → 「该单词暂无例句」；同词会话内复用已拉取结果 |
| F6 | 间隔复习 | 顶部待复习计数卡；卡片同学习卡（翻面核对）；按钮标注后果（「退回1天后」/「进入下一阶段」）；全部完成 → 「今日复习完成」页；空态「今日没有待复习内容🎉」+ 去学习入口；完成的词实时从列表移除 |
| F7 | 错题本（含 AI 讲解） | 筛选 Tab（未掌握默认带角标 / 已掌握）；条目含单词/释义一行截断/错误次数+来源标签/三操作（AI 讲解 / 标记已掌握 / 移除）；讲解区条目内展开（骨架屏 30s）；讲解失败文案且**不影响标记已掌握**；空态「太棒了，错题本空空如也」 |
| F8 | AI 学习报告 | 入口在「我的」；全屏 loading「AI 正在分析你的学习数据…」（60s）；分段渲染 概况/薄弱/建议；数据不足 → 「数据还太少，学几天再来生成报告」（不调 AI）；失败 → 提示 + 重试按钮 |
| F9 | 数据统计 | 打卡热力图近 12 周 4 档色阶，点格子 toast 显示当日词数（仅展示无跳转）；掌握度曲线近 30 天双折线（掌握度% 实线 + 每日错题 虚线）；无数据 → 「开始第一次学习后，这里会长出你的数据」 |
| F10 | 我的/个人信息 | 用户卡（头像/昵称/@用户名/注册时间/累计打卡）；功能列表（我的词书管理 / 更换头像 6 选 1 网格弹层 / AI 学习报告 / 关于）；昵称 ≤20 字即时保存；关于页含版本号 + **词库版权说明（BSD 3-Clause，KyleBing/english-vocabulary）**；退出登录 red 描边 + modal 确认后清 token 跳登录 |

### 工程结构（S3 §3.3 指定）

```
miniprogram/
├── app.js / app.json / app.wxss
├── pages/      index, study, review, mistakes, stats, me, login, setup-nickname, books, report, about
├── components/ 单词卡片、打卡日历格、图表容器
├── services/   按后端资源分文件（auth.js / book.js / study.js / review.js / mistake.js / ai.js / stats.js）
└── utils/      request.js、date.js、storage.js、constants.js
```

### 图表与热力图实现

- 热力图：用 84 个 view 网格 + 4 档色阶 CSS 类，**不引第三方库**。
- 掌握度曲线：用 `<canvas type="2d">` 手绘折线（或评估轻量库）；一期以「能正确展示数据」为准。

## 验收标准

- [ ] 微信开发者工具可编译运行，无报错、无 console 错误。
- [ ] 五 tabBar 齐全（微信上限），页面间跳转正确；统计页作为普通页由首页与「我的」两处进入。
- [ ] 开发者工具编译零错误（`cli.bat preview` 退出码 0，产出预览二维码）。
- [ ] F1–F10 在**真实后端**上逐一走通（AppID 缺失部分用账号密码登录链路代替）。
- [ ] 401 场景：手动清空 token 或后端返回 401 → 自动跳登录页并 toast「登录已过期」。
- [ ] 打卡按钮：未完成时禁用且显示 n/20；完成后可点；重复打卡提示「今日已打卡」。
- [ ] AI 降级：**停掉 ai-service 与 ai-service 均不可用时**，F5 显示内置例句 + 黄条；F7 显示「AI 讲解暂时不可用」且标记已掌握仍可用；F8 显示重试。
- [ ] 所有空态文案与 F2/F3/F6/F7/F9 的设计一致。
- [ ] 网络异常 toast「网络异常，请检查网络后重试」。
- [ ] 关于页含 BSD 3-Clause 版权说明。
- [ ] 可点击元素高度 ≥ 88rpx。

## 非目标

- 不做分享功能（原型留位，一期不实现）。
- 不做头像文件上传（仅 6 个内置头像）。
- 不做单词发音播放（`audio_url` 一期不填）。
- 不做找回密码。
- 不做真机多机型深度适配测试（以开发者工具模拟器为准，rpx 已保证基本适配）。
